# MEZNI Electronics Lab

A branded version of the supplied electrical-circuit simulation project.

## Run locally
Open `index.html` in a modern browser. No build step or server is required.

## Structure
- `index.html`: MEZNI landing page and searchable simulator directory.
- `assets/mezni-theme.css`: shared visual theme for simulator pages.
- `assets/mezni-logo-original.jpg`: supplied MEZNI logo.
- `assets/mezni-logo-concept.png`: generated visual concept (optional).
- Remaining HTML files: original interactive simulations and their physics logic.

## Interactive controls
The existing simulation controls are preserved. Adjust component values and source parameters using the controls provided on each simulator page. The available controls differ by experiment.
